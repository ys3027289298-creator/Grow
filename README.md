# 失重剧院：终幕排演

一款可直接在浏览器运行的困难级十日养成游戏。玩家要在近地轨道旧剧院断电前，培养演员、舞台工程师和灯光师，在训练、维修、资源工作、成员关系和突发事件之间取舍，并在第十天亲自完成最终演出。

## 启动

```powershell
npm install
npm start
```

然后打开：

```text
http://localhost:5173
```

本项目没有第三方运行依赖，`npm install` 只会读取 `package.json`。也可以直接用任意静态服务器打开 `index.html`。

## 测试

```powershell
npm test
```

测试覆盖：

- 成员属性成长、疲劳和压力变化
- 信任与成员关系变化
- 资源消耗和资源不足限制
- 训练成功、失败和设备后果
- 地图解锁、区域关闭和设备联动
- 十个突发事件的不同分支
- 最终演出四种结局

## 项目结构

- `index.html`：浏览器入口
- `style.css`：剧院视觉、响应式布局、动画和结局样式
- `app.js`：地图、成员面板、训练小游戏、事件弹窗、最终演出和存档界面
- `engine.js`：纯游戏规则，包括十日推进、属性、资源、设备、个人剧情、事件和结局
- `engine.test.js`：Node 自动化测试
- `server.js`：零依赖本地静态服务器

## 主要操作

1. 在右侧选择一名或多名成员。
2. 在地图中切换主舞台、后台、排练室、灯光室、维修舱、储藏间和观众席。
3. 使用行动次数执行台词、节奏、灯光、维修、临场反应或团队排练。
4. 训练必须完成实际操作：
   - 台词：按情绪顺序点击
   - 节奏：收缩环进入节拍区时踩拍
   - 灯光：按剧情区域和颜色选择灯光
   - 维修：按安全流程排查电路
   - 反应：处理三个随机舞台问题
   - 团队：安排成员位置和出场任务
5. 能源、零件、资金、排练时间、道具和期待不足都会产生真实后果。
6. 每天巡查会触发突发事件；选项可能需要能力、关系、设备或资源条件。
7. 第十天先确认站位、机械设备、灯光顺序和备用方案，再亲自处理四次现场变化。

## 推荐十分钟演示路线

- 第 1-2 天：顾壑维修供电和升降台，林杳进行一次台词训练，尽快解锁灯光室。
- 第 3 天：林杳、米卡、晴文参加团队排练，提升关系和期待。
- 第 4-6 天：林杳专注台词，米卡专注灯光，晴文专注临场反应，顾壑继续维修。
- 第 7 天：处理关键故障，必要时让疲劳成员休息，避免连续高压安排。
- 第 8-9 天：完成两次团队排练，保留至少 1 个零件并把供电、灯轨和升降台维持在 60% 以上。
- 第 10 天：主演林杳、替补晴文、工程顾壑、第一灯光米卡；根据现场提示手动完成处置。

推荐路线不会自动执行，所有训练、事件和最终演出仍需玩家操作。

## 存档

游戏使用浏览器 `localStorage` 自动保存，也可以点击“保存”。保存内容包括日期、成员状态、关系、资源、设备、事件记录、区域解锁和最终演出进度。关闭浏览器后点“继续游戏”即可读取。重新开始会明确提示并清除存档。

## 结局

最终评分由成员属性、成长路线、疲劳、压力、团队信任、关系、设备完整度、观众期待、站位方案和玩家四次现场操作共同决定：

- 完美谢幕
- 演出完成但剧院关闭
- 中途失控后勉强结束
- 演出失败

结局页会显示总分、成员终态、关键现场操作、重要事件和失败短板。
