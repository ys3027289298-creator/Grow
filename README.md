# 🎭 失重剧院：终幕排演

> 近地轨道旧剧院即将在 **10 天后** 失去能源。你是最后一任舞台监督，要带领主演、替身、灯光师与工程师，在资源枯竭、设备老化与突发事件中完成最后一场演出。

纯原生 HTML / CSS / JavaScript（ES Modules）实现的**困难级养成游戏**，零外部依赖、无需安装任何 npm 包，双击或用内置静态服务器即可在浏览器中运行。

---

## 一、启动方法

**环境要求：** Node.js 18+（开发/测试用，推荐 Node 20/22）。游戏本身不依赖任何第三方库。

```powershell
# 在当前项目文件夹中
npm start          # 启动内置静态服务器（默认端口 8123）
```

然后在浏览器打开：

```
http://localhost:8123/
```

也可以直接双击 `index.html` 打开（建议使用 Chrome / Edge）。

主菜单提供：**开始游戏 · 继续游戏 · 重新开始 · 设置**，另有「操作说明与推荐路线」与「事件记录」入口。无需注册登录，打开即玩，完整一局约 10 分钟。

## 三、主要操作

### 每日循环（第 1–9 天）

1. **晨间安排**：顶栏查看日期、行动点（每天 4 点）、能源、零件、资金、排练进度、期待值与剧院状态。
2. **地图移动**：左侧点击主舞台 / 后台 / 排练室 / 灯光室 / 维修舱 / 储藏间 / 观众席切换区域。
3. **训练与工作**：中间场景点击行动卡片。除休息、谈心、零工、采购外，训练都会进入**可操作小游戏**。
4. **突发事件**：每天结束前必须处理一次事件，至少两个选项，部分选项需要能力 / 关系 / 资源达标。
5. **夜间总结**：点击「结束今天」，自然疲劳、设备老化、延迟影响结算后进入下一天。能源配额随天数收紧。

### 六个操作型小游戏（核心操作不可跳过）

- **台词训练**：按正确句序点亮打乱的字词。
- **节奏训练**：收缩圆环进入判定区时点击或按空格，共 8 拍。
- **灯光操作**：读剧情提示，先选舞台区域（左/中/右/天幕）再选灯光颜色。
- **舞台维修**：按「断电→定位→更换→试通→复电」流程顺序操作，误操作扣分。
- **临场反应**：舞台随机突变，3.6 秒内选出正确救场方案，越快分越高。
- **团队排练**：把两名成员分配到前场 / 后场岗位，选择开场顺序与同步 / 即兴配合。

小游戏得分 = **玩家操作质量 × 成员状态系数 + 成员属性 + 性格加成**。失败会浪费能源、增加压力、降低信任，维修 / 灯光失败还会损坏设备。

### 成员与路线

| 成员 | 定位 | 路线（剧情第 2 段抉择） |
| --- | --- | --- |
| 林·奥德赛 | 主演（完美主义） | 群戏核心 / 独角主演 |
| 凯·脉冲 | 替身（即兴派） | 节奏担当 / 现场救场人 |
| 织女星 | 灯光师（精密冷静） | 经典守光 / 极光作者 |
| 老鲍 | 工程师（老派可靠） | 可靠工程师 / 极限改造师 |

每名成员有 **3 段个人剧情**，通过「谈心」积累信任触发；剧情会解锁区域、决定路线并为最终演出提供加成。

### 资源与区域解锁

- 能源、零件、资金均有限：零工赚资金但消耗体力且有受伤风险；采购要花钱；后期每日能源上限下降。
- **灯光室**：与织女星完成第 1 段剧情解锁。
- **维修舱**：在主舞台完成一次应急检修解锁。
- **观众席**：第 4 天自动开放，可路演提升期待值。

### 最终演出（第 10 天）与四种结局

开场前确认主演 / 替补 / 灯光师 / 工程师站位及灯光顺序、备用方案；演出中依次处理**灯光切换 → 设备修复 → 现场调度**三次现场变化（复用三类小游戏）。最终评分综合成员属性、疲劳、关系、设备、道具、排练度、期待值与现场操作：

- 🌟 **完美谢幕**（约 82 分以上且三段全成功）
- 🎭 **演出完成，但剧院关闭**（约 58 分以上且至少两段成功）
- 🌀 **中途失控，勉强结束**（约 38 分以上）
- 🥀 **演出失败**

结局页显示总分、准备分 / 现场分、观众反馈、每名成员的成长与路线、近 5 个关键选择、失分原因与通关耗时。

### 保存

- 每次行动结算、夜间总结、演出判定后自动保存到浏览器 `localStorage`（auto 存档），关闭浏览器后可「继续游戏」。
- 设置中可写入手动存档；重新开始 / 清除存档前均有二次确认。

## 四、录屏推荐路线（仍需亲手操作）

1. **第 1 天**：织女星「谈心」解锁灯光室 → 老鲍主舞台「应急检修」解锁维修舱。
2. **第 2–3 天**：林练台词、凯练临场反应、织女星练灯光、老鲍深度维修；至少一次团队排练抬排练度。
3. **第 4 天起**：观众席开放，穿插 1–2 次路演把期待值拉到 50+；资金紧张时让体力高的凯做一次零工。
4. **剧情抉择**：林选群戏 / 凯选救场 / 织女星补完极光 / 老鲍稳妥修补，容错最高。
5. **第 7–9 天**：补齐设备完整度到 55 以上，第 9 天安排疲劳高的成员休息，把全员疲劳压到 60 以下。
6. **第 10 天**：按提示完成三次现场操作，冲击完美谢幕。

想录失败结局：全程不训练、不维修、不处理成员状态，最终演出三次全部误操作即可。

## 五、项目结构

```
index.html                游戏页面（主菜单 + 三栏游戏界面 + 模态层 + 小游戏层）
server.mjs                零依赖静态文件服务器（npm start）
package.json              start / test 脚本
css/style.css             暗色轨道剧院视觉、响应式布局、小游戏与动画样式
js/data.mjs               成员/区域/行动定义、初始状态、存档数据结构
js/engine-actions.mjs     训练结算、休息/零工/采购、疲劳压力过载、夜间总结
js/engine-events.mjs      12 个突发事件、条件分支、延迟效果
js/engine-story.mjs       4×3 段个人剧情、发展路线、区域解锁
js/engine-finale.mjs      演出配置、三次现场判定、四结局评分
js/engine-save.mjs        localStorage 存档（带内存兜底，便于 Node 测试）
js/minigames.mjs          六个可实际操作的小游戏
js/ui.mjs                 模态框、Toast、WebAudio 音效
js/main.mjs               主控制器：渲染、流程编排、事件/剧情弹窗、演出界面
tests/                    61 个 Node 测试 + 浏览器端到端流程页
```

所有业务规则都写在 `js/engine-*.mjs` 的纯函数中，UI 与逻辑分离，同一套逻辑被浏览器与自动化测试共用。
